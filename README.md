# نظام إدارة الإجازات والمستندات (Leave & Document Management System v4)

نظام إلكتروني متكامل لإدارة وتتبع إجازات الموظفين وسجلات الخدمة واحتساب الأرصدة التراكمية، مع إدارة متكاملة لأرشفة بطاقات الدوام والإجازات الورقية، مصمم للعمل في بيئة سطح المكتب المعزولة محلياً بدقة وكفاءة وأمان عالٍ، مع واجهة مستخدم عربية عصرية تدعم الوضعين الفاتح والداكن.

---

## ✨ المميزات والوظائف الأساسية (Key Features)

### 1. 👥 إدارة بيانات الموظفين (Employee Management)
* **إضافة موظف جديد:** تسجيل البيانات الشخصية والوظيفية (الاسم الرباعي، الرقم الوظيفي، رقم كرت الإجازة، الجنس، المسمى الوظيفي، العنوان الوظيفي، الدائرة/القسم، موقع العمل، تاريخ المباشرة/التعيين، رصيد الإجازات الافتتاحي).
* **تعديل وتحديث البيانات:** إمكانية تعديل بيانات أي موظف أو أرصدته السنوية بسهولة مع الحفاظ على ترابط السجلات وسجل التعديلات الذري.
* **إلغاء التفعيل والأرشفة:** دعم تجميد أو إيقاف تفعيل الموظفين المنتهية خدمتهم دون فقدان سجلاتهم التاريخية.
* **شاشة موحدة لجميع الموظفين:** جدول بيانات تفاعلي مزود ببحث لحظي وفلترة سريعة مع ترقيم موحد (15 صفاً لكل صفحة).

### 2. 🔄 نقل الموظفين خارجياً وإلغاء النقل (Employee Transfer & Reinstatement)
* **نقل موظف خارج الدائرة:** إمكانية نقل الموظف إلى جهة خارجية مع توثيق:
  * رقم الأمر الإداري الخاص بالنقل (`TransferOrderNumber`) مع الحفاظ الصارم على الأصفار البادئة (مثل `00123`).
  * تاريخ صدور أمر النقل الإداري (`TransferOrderDate`).
  * جهة النقل أو ملاحظات وتفاصيل النقل (`TransferNotes`).
* **إلغاء النقل واستعادة الموظف (Reinstatement):** إمكانية إلغاء حالة النقل وإعادة تفعيل الموظف كنشط اعتيادي بنقرة واحدة عبر `cancelEmployeeTransfer`، مع تصفير حقول النقل وإعادة `IsTransferred = 0`.
* **الحفظ الذري في سجل التدقيق (Atomic Audit Logging):** توثيق كل عملية نقل أو إلغاء نقل تلقائياً في جدول التدقيق `AuditLog` ضمن معاملة ذرية موحدة (`db.transaction()`) تضمن عدم حدوث أي انفصال بين حالة الموظف وسجل التدقيق حتى في حال انقطاع التيار الكهربائي المفاجئ.
* **عزل الموظفين المنقولين:** استثناء الموظف المنقول تلقائياً من قوائم الإجازات الحالية النشطة، والتنبيهات المباشرة، وتقارير الأرصدة الحرجة، وإحصائيات التراكم السنوي، مع وسم بصري توضيحي مميز (`منقول خارجياً`) في دليل الموظفين وسهولة تامة للوصول إلى كامل سجلاته وأرشيفه السابق.

### 3. 📝 تسجيل ومعالجة الإجازات (Leave Transactions)
* **دعم كافة أنواع الإجازات:**
  * إجازة اعتيادية (براتب تام).
  * إجازة مرضية (بفترات 30 يوماً براتب تام / 45 يوماً بنصف راتب / 45 يوماً بربع راتب).
  * إجازة بلا راتب (تخصم من مدة الخدمة الصالحة للرصيد).
  * إجازات أخرى (أمومة، حج، عدة وفاة، إلخ).
* **🛡️ نظام منع تداخل الإجازات (Strict Overlap Prevention):** فحص تاريخي وتلقائي دقيق يمنع تسجيل أو تعديل أي إجازة تتعارض أو تتقاطع في فترتها الزمنية مع إجازة سابقة لنفس الموظف، مع إظهار تنبيه توضيحي مفصل.
* **احتساب آلي للأرصدة:** خصم وإضافة الأيام تلقائياً حسب نوع الإجازة وقوانين الخدمة المدنية النافذة.
* **تعديل وإلغاء الإجازات:** إمكانية تعديل تواريخ الإجازة أو إلغائها مع استرجاع الرصيد وتوثيق الحركة في سجل التدقيق.

### 4. 📂 إدارة وأرشفة مستندات وبطاقات الموظفين (Document Archiving & Direct A4 Print)
* **أرشفة بطاقات الدوام والإجازات:** إمكانية رفع وتخزين بطاقات الدوام الشهرية (`TIME_CARD`) وبطاقات الإجازات السنوية (`LEAVE_CARD`) والمستندات الرسمية بصيغ (PDF, JPG, PNG) لكل موظف.
* **🖨️ طباعة مباشرة بقياس A4:** زر طباعة سريع `🖨️ طباعة` بجانب كل بطاقة مستند في نافذة استعراض المستندات، يقوم بإرسال المستند للطباعة الفورية بحجم ورقة A4 القياسية مع التوافق الكامل مع Windows 7 فما فوق.
* **معاينة مدمجة وتنزيل آمن:** استعراض فوري للوثائق والصور داخل التطبيق دون مغادرة النظام، مع إمكانية حفظ نسخة محلية.
* **تخصيص مسار التخزين:** إمكانية نقل وتعيين مسار مجلد تخزين المستندات من إعدادات النظام إلى أي قرص أو مجلد محلي أو شبكي مع الهجرة الآلية الآمنة للملفات.

### 5. 📊 لوحة المؤشرات والإجازات حالياً (Dashboard & Active Leaves)
* **الإجازات حالياً:** كشف فوري لجميع الموظفين المتمتعين بإجازات نشطة حالياً مع احتساب الأيام المنقضية والمتبقية، وحالة وتاريخ العودة للمباشرة.
* **⚡ فلتر المباشرة السريع:** زر فلترة سريع بنقرة واحدة `⚡ المباشرة قريباً (≤ 3 أيام)` لعرض الموظفين الذين أوشكت إجازاتهم على الانتهاء.
* **قائمة فرز متقدمة:** إمكانية فرز النتائج حسب:
  * الأقرب للمباشرة (الترتيب الافتراضي).
  * الأبعد للمباشرة.
  * أبجدياً باسم الموظف.
* **بطاقات الإحصائيات (KPIs):** إجمالي الموظفين النشطين، إجمالي الإجازات الحالية، عدد الإجازات المنتهية قريباً، وحركات الشهر الحالي.
* **جدول تفاعلي مع ترقيم 15 صفاً:** إمكانية البحث المباشر والفلترة والتصفح والتعديل الفوري بسلاسة.

### 6. 📑 تقارير الأرصدة والتراكم السنوي (Balance & Accumulation Reports)
* **كشف تنبيهات الأرصدة الحرجة:** تحديد ومتابعة الموظفين ذوي الأرصدة المنخفضة مع إمكانية تحديد حد الرصيد الحرج يدوياً.
* **زر تطبيق مخصص وفلترة تفاعلية:** حقل إدخال الحد الحرج مزود بزر **"تطبيق"** مخصص، مع دعم الضغط على `Enter`، ورسالة إرشادية توضيحية للمستخدم، وتحديث تلقائي لبطاقة المؤشر الإحصائي (KPI).
* **كشف تراكم الإجازات السنوي:** كشف إحصائي موحد على مستوى الدائرة يوضح إجمالي الأيام المستهلكة موزعة حسب النوع (اعتيادية، مرضية، أخرى) وعدد الحركات لكل موظف خلال السنة المختارة.
* **ترقيم صفحات مستقل (15 صفاً):** ترقيم منفصل لكل من جدولي الأرصدة الحرجة وتراكم الإجازات.

### 7. 📗 تصدير Excel الاحترافي (Advanced Excel Export)
* **تصدير كشف تاريخ الإجازات:** كشف كامل ومفصل لإجازات موظف معين مع رصيده الحالي وحركاته السابقة.
* **تصدير كشف جميع الموظفين:** تصدير السجل العام للموظفين بأرصدتهم ومواقع عملهم.
* **تصدير كشف الإجازات حالياً:** كشف رسمي بالموظفين المجازين حالياً ومواعيد مباشرتهم.
* **تصدير تقرير الأرصدة والتراكم:** ملف متعدد الأوراق (Sheet للأرصدة الحرجة + Sheet للتراكم السنوي).
* **تصميم رسمي متقن:**
  * تنسيق جداول ملوّنة متناسقة مع اتجاه كامل من اليمين لليسار (RTL).
  * ترويسة وزارية/إدارية رسمية مع رقم وتاريخ التصدير التلقائي.
  * حقول التواقيع والاعتماد الرسمية الثلاثية بأسفل كل تقرير.
  * ملائمة الصفحة التلقائية للطباعة المباشرة (Fit to Page Landscape).

### 8. 🛡️ سجل التدقيق ومراقبة حركات النظام (Audit Logs)
* **توثيق شامل:** تسجيل دقيق ولحظي لجميع حركات الإضافة، التعديل، الحذف، النقل وإلغاء النقل، أرشفة المستندات، تنظيف المساحة، تغيير الحالة، النسخ الاحتياطي والاستعادة.
* **لقطات البيانات (Snapshots):** إمكانية معاينة لقطة تفصيلية للبيانات قبل وبعد كل عملية لمطابقة التغييرات.
* **فلترة متقدمة وترقيم 15 صفاً:** فلترة حسب نوع العملية، الكيان (موظف / إجازة / نظام)، والمدى الزمني.
* **👤 معمارية جاهزة للمستخدمين:** تم تهيئة جدول سجل التدقيق بالحقل `UserID` لربطه مستقبلاً بنظام الحسابات والصلاحيات دون الحاجة لتعديل هيكلية قاعدة البيانات.

### 9. 📦 النسخ الاحتياطي المجمّع الشامل والاستعادة (Bundled Backup & Restore .hbak / .zip)
* **النسخ الاحتياطي المجمّع (Bundle System):** دمج ملف قاعدة البيانات `leave_management.db` مع مجلد المستندات المؤرشفة `EmployeeDocuments/` وفهرس النسخة `manifest.json` في ملف أرشيف واحد يحمل الامتداد المعتمد `.hbak` (أو `.zip`).
* **استعادة ذكية وآمنة:** فحص تلقائي لسلامة قاعدة البيانات والمستندات قبل الاستعادة، مع تحذير المستخدم في حال كانت النسخة المستعادة أقدم تاريخاً من مستندات موجودة حالياً.
* **نسخة أمان فورية (Safety Backup):** أخذ نسخة احتياطية مجمعة تلقائياً قبل البدء في استرجاع أي ملف لحماية البيانات من أي خطأ غير مقصود.
* **نسخ احتياطي تلقائي دوري:** جدولة ذكية في الخلفية تحفظ حزم `.hbak` بشكل دوري مع إدارة التدوير وحذف النسخ القديمة الزائدة عن الحد الأقصى دون حظر واجهة المستخدم.
* **توافق كامل مع النسخ السابقة:** دعم استرجاع النسخ الفردية القديمة (`.db`) إلى جانب الحزم الحديثة (`.hbak`).

### 10. 🗑️ تنظيف المستندات المحذوفة وتوفير المساحة (Soft-Deleted Files Purge)
* **حذف آمن مبدئي (Soft Delete):** تظل الملفات المحذوفة محفوظة على القرص مع إمكانية فحص حجمها وعدم حذفها تلقائياً.
* **إحصائيات فورية للمساحة:** شاشة إعدادات النظام تعرض عدد المستندات المحذوفة وإجمالي المساحة المشغولة بها على القرص.
* **إفراغ يدوي محمي بتأكيد صريح:** زر تنظيف يدوي لحذف المستندات المعلمة كمحذوفة نهائياً من القرص الصلب وتفريغ مساحة التخزين مع تسجيل تفاصيل العملية في سجل التدقيق.

### 11. 🎨 تجربة المستخدم والمظهر (Modern UI & Theme Support)
* **الوضع الليلي / الفاتح (Dark / Light Mode):** دعم كامل للثيمين الفاتح والداكن مع زر تبديل سريع بالشريط الجانبي، وضبط دقيق للتباين البصري لمنع أي تداخل بين أوضاع العرض.
* **توحيد القياسات والارتفاعات (42px):** توحيد قياسي متناسق لجميع أشرطة البحث، أزرار التصدير، أزرار البحث المتقدم، قوائم الفرز وأزرار التطبيق.
* **تصميم متجاوب بالكامل:** دعم مختلف دقات الشاشات وتجاوب شريط التمرير والقوائم عند تصغير النافذة أو الارتفاعات المنخفضة.
* **ترقيم صفحات موحد وثابت:** تطبيق مقياس 15 صفاً في كل الشاشات لمنع بطء التمرير وضمان سرعة استجابة فائقة.

## 🔒 هندسة الأمان ومقاومة انقطاع الطاقة (Resilience & Crash Hardening)

تم تزويد النظام بـ 5 آليات حماية متقدمة تجعله فائق الصمود ضد انقطاع التيار المفاجئ والانهيارات:

1. **العمليات الذرية المتكاملة (Atomic Transactions via `db.transaction()`):**
   * تغليف جميع عمليات تعديل بيانات الموظفين، تغيير الحالة، الإجازات، النقل الخارجي، وإلغاء النقل داخل معاملات SQLite ذرية تتضمن كتابة حركة التدقيق `AuditLog`. في حال انقطاع التيار الكهربائي أثناء العملية، يتم التراجع كلياً (Rollback) ولا تترك أي بيانات ناقصة أو سجلات معلقة.
2. **مطابقة وتنظيف الملفات الفيزيائية اليتيمة (Orphan File Reconciliation):**
   * عند إضافة مستند، يتم نسخه أولاً إلى مجلد التخزين ثم تسجيله في قاعدة البيانات. في حال حدث انقطاع مفاجئ بين مرحلتي النسخ والتسجيل، تقوم آلية الفحص والمطابقة التلقائية بحذف الملفات اليتيمة غير المسجلة بقاعدة البيانات لمنع هدر مساحة التخزين.
3. **التراجع التلقائي عند تعثر الاستعادة (`_emergencyRollback`):**
   * قبل البدء في استعادة أي نسخة احتياطية مجمعة، يتم أخذ نسخة أمان فورية `_pre_restore_safety_backup.hbak`. إذا تعثرت عملية الاستخراج أو انقطع التيار، يقوم النظام باستعادة بيئة العمل السابقة تلقائياً بالكامل دون فقدان للبيانات.
4. **تأمين النسخ الاحتياطي التلقائي (Non-blocking & Corrupt Handling):**
   * تجري عملية النسخ الاحتياطي الدوري في الخلفية بمسار آمن دون تجميد واجهة المستخدم، ويتم فحص اكتمال ملف الحزمة وعدم اعتماد النسخ المبتورة أو التالفة.
5. **تأمين ملفات قاعدة البيانات بنمط WAL والمفاتيح الأجنبية:**
   * تفعيل دائم لـ `PRAGMA journal_mode = WAL` لحماية صفحات البيانات من الفساد عند التوقف المفاجئ، مع تفعيل `PRAGMA foreign_keys = ON` للحفاظ على تكامل العلاقات.

## 🛡️ درع حماية قنوات الاتصال IPC ضد الانحدار (Permanent IPC Regression Guard)

* يتضمن المشروع وحدة اختبار آلية صارمة (`tests/ipcChannelGuard.test.js`) تفحص مطابقة **47 قناة IPC** مستخدمة في النظام بين:
  * معالجات العمليات الرئيسية في الخلفية (`src/main/ipc/*Handlers.js` و `src/main/main.js`).
  * القائمة البيضاء المعتمدة في جسر الأمان (`src/main/preload.js` -> `VALID_CHANNELS`).
* **الهدف:** منع حدوث خطأ `Channel not allowed` أو فقدان معالج أي قناة أثناء أي تحديث أو تعديل برمجي مستقبلي.

## 💻 متطلبات النظام وبيئات التشغيل (System Requirements)

يدعم النظام العمل على أنظمة التشغيل **Windows 7 (SP1) / Windows 8 / Windows 8.1 / Windows 10 / Windows 11** مع دعم صريح لكلا معماريتي المعالج **64-بت (x64)** و **32-بت (ia32)** لضمان العمل على أجهزة Windows 7 القديمة والحديثة على حد سواء.

### ⚠️ متطلبات إلزامية لأجهزة Windows 7 و Windows 8.1:
نظراً لاعتماد النظام على محرك Electron 22 و C++ Native Modules لقاعدة بيانات SQLite، تتطلب أجهزة Windows 7 توافر المتطلبات التالية قبل التشغيل:

1. **حزمة Visual C++ Redistributable (2015–2022) x64/x86:**
   * يجب تثبيت حزمة `vc_redist` الرسمية من موقع Microsoft لتشغيل الإضافات الأصلية لقاعدة البيانات (`better-sqlite3`).
2. **تحديثات Universal C Runtime (UCRT) لنظام Windows 7:**
   * **تحديث [KB2999226](https://support.microsoft.com/help/2999226):** تحديث Universal C Runtime الأساسي.
   * **تحديث [KB3080149](https://support.microsoft.com/help/3080149):** تحديث دعم بروتوكولات الاتصال وتوافق مكتبات C++.
   * **Windows 7 Service Pack 1 (SP1)** مع دعم توقيع كود SHA-2 (تحديثات KB4474419 و KB4490628).

> **ملاحظة فنية:** بالنسبة لأنظمة **Windows 10 و Windows 11**، تكون هذه المكونات مدمجة ومحدثة مسبقاً وتعمل الحزمة تلقائياً دون الحاجة لتثبيت برامج إضافية.
